# Port Tunnel

Windows 托盘小工具：把本机 TCP 端口经 frp 映射到公网（配置来自 ssh-bridge，编译进二进制）。

## 使用

1. 运行 `output\PortTunnel.exe`
2. 勾选常用协议（RDP/SSH/HTTP/HTTPS/VNC/DNS…，含 **TCP/UDP**），或自定义端口
3. 点 **启动映射**
4. 连通后选中一行，**复制外网地址**（`sshbridge.online:端口 (TCP|UDP)`）

关闭窗口会藏到托盘；托盘右键可 **开机自启** / 退出。

## 外网端口规则

| 本机 L | 主池（100 口，不重叠） | prefer（可跨段优先） |
|--------|------------------------|----------------------|
| 1–654 | `L×100`…`+99` | 段起点 |
| ≥655 | `50000+(L%150)×100`… | `L×10`（3389→**33890**） |

状态「公网通·本机无服务」表示 frps 已通但本机端口无进程在听。

## 编译

```bat
build.bat
```
