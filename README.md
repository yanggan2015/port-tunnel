# Port Tunnel

Windows 托盘小工具：把本机 TCP 端口经 frp 映射到公网（配置来自 ssh-bridge，编译进二进制）。

## 使用

1. 运行 `output\PortTunnel.exe`
2. 勾选 **3389 远程桌面**，或添加其它本机端口
3. 点 **启动映射**
4. 连通后选中一行，**复制外网地址**（`sshbridge.online:外网端口`）

关闭窗口会藏到托盘；托盘右键可退出。

## 外网端口规则

每本机端口固定 **100** 个候选，仪表盘自动选空闲口：

| 本机 L | 外网池 | 优先 |
|--------|--------|------|
| 1–654 | `L×100` … `+99` | 段起点 |
| 655–6553 | 含 `L×10` 的整百段 | `L×10`（3389→**33890**，池 **33800–33899**） |
| ≥6554 | `40000+(L%350)×100` 起 | 段起点 |
